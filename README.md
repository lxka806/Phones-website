# Phones Website

მობილური ტელეფონების ონლაინ კატალოგი და მაღაზიის ვებ-აპლიკაცია. პროექტი საშუალებას აძლევს მომხმარებლებს დაათვალიერონ ტელეფონების მოდელები, შეამოწმონ მონაცემები და მართონ პროდუქციის სია.

## 🚀 ფუნქციონალი (Features)

* **პროდუქციის კატალოგი:** მობილური ტელეფონების სიის, ფასებისა და ტექნიკური მახასიათებლების დათვალიერება.
* **CRUD ოპერაციები:** ახალი მოდელის დამატება, მონაცემების განახლება და წაშლა.
* **ფილტრაცია და ძებნა:** ტელეფონების ძებნა ბრენდის, ფასისა თუ პარამეტრების მიხედვით.

## 🛠 ტექნოლოგიები (Tech Stack)

* **Backend:** Python (Django)
* **Frontend:** HTML5, CSS3, JavaScript
* **Database:** SQLite / PostgreSQL

## 📦 პროექტის გაშვება

1. **რეპოზიტორიის კლონირება:**
   ```bash
   git clone [https://github.com/lxka806/Phones-website.git](https://github.com/lxka806/Phones-website.git)
   cd Phones-website

```

2. **ვირტუალური გარემოს შექმნა და აქტივაცია:**
```bash
python -m venv venv

# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

```


3. **დამოკიდებულებების ინსტალაცია:**
```bash
pip install -r requirements.txt

```


4. **მიგრაციები და სერვერის გაშვება:**
```bash
python manage.py migrate
python manage.py runserver

```


აპლიკაცია ხელმისაწვდომი იქნება მისამართზე: `http://127.0.0.1:8000/`
